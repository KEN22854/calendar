# Календарь записи — онлайн-школа

**Русский** | [English](README.en.md)

Веб-приложение для записи учеников на занятия по абонементам (4, 8 или 12 занятий в месяц)
с админ-панелью, историей всех записей и гибким расписанием. Интерфейс в розовых тонах.

**Стек:** Node.js, Express, SQLite (better-sqlite3), JWT, чистые HTML/CSS/JS без сборки.

## Возможности

- **Ученик** записывается на одну неделю вперёд: понедельник–суббота, воскресенье — выходной.
- **Абонементы** на 4, 8 или 12 занятий в месяц назначает администратор.
- **Админ-панель:** календарь месяца, список записей, ученики, абонементы, расписание.
- **История (аудит):** все записи за всё время — календарём и списком, с экспортом в CSV.
- **Расписание:** стандарт — каждый час; на отдельный день можно добавить или отключить время.

## Запуск

Нужен Node.js 18+.

```bash
npm install
cp .env.example .env
node server/index.js
```

Откройте http://localhost:3000. На Windows вместо `cp` используйте `copy .env.example .env`.
Если PowerShell блокирует `npm`, запускайте сервер напрямую: `node server/index.js`.

При первом запуске создаются база данных и администратор из `.env`.
**Перед публикацией смените `ADMIN_PASSWORD` и `JWT_SECRET`.**

## Настройки (`.env`)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PORT` | Порт сервера | `3000` |
| `JWT_SECRET` | Секрет для токенов входа — длинная случайная строка | — |
| `JWT_EXPIRES_IN` | Срок действия входа | `7d` |
| `DB_PATH` | Путь к файлу базы SQLite | `./data/booking.db` |
| `SEED_ADMIN` | Создать администратора при старте, если его нет | `true` |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | Логин и пароль администратора | — |

Сменить пароль существующего администратора: `npm run seed` (берёт значения из `.env`).

## Страницы

| Адрес | Для кого | Что там |
|---|---|---|
| `/register`, `/login` | все | Регистрация и вход |
| `/` | ученик | Расписание недели и запись |
| `/my-bookings` | ученик | Мои записи и отмена |
| `/admin` | админ | Админ-панель |

## Ученик

- Видна только одна неделя: **понедельник–суббота**. Воскресенье — всегда выходной.
- В воскресенье открывается уже **следующая** неделя.
- Прошедшие дни неактивны, записаться на них нельзя.
- Запись возможна, только если абонемент активен, дата в сроке его действия и остались занятия.
- Отмена записи возвращает занятие в абонемент.

## Абонементы

- Типы: **4, 8 или 12 занятий в месяц**. Назначает админ на вкладках **Ученики** и **Абонементы**.
- Срок — месяц от даты начала включительно (01.10 → 31.10). Предыдущий активный абонемент закрывается.
- Админ может изменить количество занятий (всего и использовано), дату окончания и активность.

## Время занятий

- **Стандартное расписание** (вкладка **Слоты**) — только целые часы, действует на все дни.
  По умолчанию 09:00–20:00.
- **Отдельный день** — кнопка ⚙ у дня в календаре админки. Стандартные часы можно отключить
  на этот день, нестандартное время (например, 14:30) — добавить и удалить. Другие дни не меняются.
- Время, на которое есть запись, нельзя отключить или удалить — сначала отмените запись.

## Админ: ручная запись

На вкладках **Календарь** и **Список броней** есть кнопка **«+ Создать бронь»**:
ученик, дата (можно воскресенье или прошедшую), время, Telegram и телефон.
- Если у ученика есть активный абонемент с остатком — занятие списывается (можно отключить).
- Ограничение «только текущая неделя» на админа не действует.

## История (аудит)

Вкладка **История (аудит)** показывает **все** записи — запланированные, прошедшие и отменённые:
- два вида: **Календарь** (ровно один месяц, клик по дню — все записи дня) и **Список** (таблица со страницами);
- фильтры по ученику, статусу и датам, счётчики по статусам, экспорт в CSV;
- кнопка «История» на вкладке **Ученики** открывает записи конкретного ученика.

### Архивация

- Каждый день в **00:01 (Москва)** прошедшие записи переносятся в архив (`bookings_archive`)
  и пропадают из расписания, но остаются в истории навсегда. То же делается при запуске сервера.
- Будущие записи не трогаются.
- Отменённые записи тоже сохраняются в истории с пометкой, кто отменил.

## API (кратко)

Все запросы `/api/admin/*` требуют токен администратора (`Authorization: Bearer …`).

| Метод и путь | Описание |
|---|---|
| `POST /api/register`, `POST /api/login` | Регистрация и вход |
| `GET /api/bookings?date=` / `POST /api/bookings` | Расписание дня / запись ученика |
| `GET /api/my-bookings`, `DELETE /api/bookings/:id` | Мои записи / отмена |
| `GET /api/my-subscription` | Мой абонемент |
| `GET/POST/PATCH/DELETE /api/admin/subscriptions` | Абонементы |
| `GET/POST/DELETE /api/admin/slots/day` | Время на конкретный день |
| `GET /api/admin/history`, `GET /api/admin/history.csv` | История: `from`, `to`, `user`, `status=active\|done\|cancelled` |
