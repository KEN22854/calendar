# Календарь записи — онлайн-школа

Запись учеников на занятия по абонементам (4, 8 или 12 занятий в месяц) с админ-панелью.
Node.js + Express + SQLite.

## Запуск

```bash
npm install
cp .env.example .env   # задайте свой JWT_SECRET и пароль администратора
node server/index.js   # http://localhost:3000
```

## Время занятий (админ)

- **Стандартное расписание** (вкладка **Слоты**) — только целые часы, действует на все дни.
  По умолчанию 09:00–20:00, создаётся при первом запуске.
- **Отдельный день** — кнопка ⚙ у дня в календаре админки. Стандартные часы можно отключить
  на этот день, нестандартное время (например, 14:30) — добавить и удалить. Другие дни не меняются.
- Время, на которое есть запись, нельзя отключить или удалить — сначала отмените запись.
- Удаление часа из стандарта **не ломает** существующие брони — в `bookings.time_slot` хранится текст.

## Ручное создание брони (админ)

На вкладках **Календарь** и **Список броней** есть кнопка **«+ Создать бронь»**.
Админ выбирает пользователя, дату (можно воскресенье / прошедшую), слот, Telegram и телефон.
- Если у пользователя есть активный абонемент с остатком — занятие списывается (чекбокс «Списать занятие»).
- Если абонемента нет — бронь создаётся без списания.
- Админские брони не подчиняются ограничению «только текущая неделя пн–сб».

## Неделя записи (ученик)

- Ученик видит только одну неделю: **понедельник–суббота**. Воскресенье — всегда выходной.
- В воскресенье открывается уже **следующая** неделя (текущая к этому моменту прошла).
- Прошедшие дни недели показываются неактивными, записаться на них нельзя.

## Абонементы

- Типы: **4, 8 или 12 занятий в месяц**. Назначает админ (вкладки **Ученики** и **Абонементы**).
- Срок: месяц от даты начала включительно (01.10 → 31.10). Предыдущий активный абонемент закрывается.
- Админ может вручную изменить всего/использовано занятий, дату окончания и активность (кнопка «Изменить»).
- Ученик записывается, только если абонемент активен, дата занятия в сроке действия и остались занятия.
- Отмена записи возвращает занятие в абонемент.

## Авто-архивация прошедших дней

- Каждый день в **00:01 Europe/Moscow** брони с `date < сегодня` переносятся в `bookings_archive` (reason `past-day`, в воскресенье — `sunday`) и удаляются из `bookings`.
- Будущие брони (например, созданные админом на следующую неделю) не трогаются.
- При старте сервера выполняется та же проверка (догоняющая).
- Отменённые записи тоже не удаляются бесследно: reason `cancel-user` / `cancel-admin`.

## История (аудит)

Вкладка **История (аудит)** показывает **все** записи за всё время — запланированные, прошедшие и отменённые:
- два вида: **Календарь** (месяц, клик по дню — все записи дня) и **Список** (таблица с пагинацией);
- фильтры по ученику, статусу и (в списке) диапазону дат, счётчики по статусам;
- экспорт CSV с теми же фильтрами, кнопка «Заархивировать прошедшие» (reason `manual`);
- из вкладки **Ученики** кнопка «История» открывает историю конкретного ученика.
- API: `GET /api/admin/history`, `GET /api/admin/history.csv` (параметры `from`, `to`, `user`, `status=active|done|cancelled`).
